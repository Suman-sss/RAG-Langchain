# Enterprise Operations Intelligence Platform

This repository is a guided learning project for building enterprise-grade RAG and agentic AI systems with a strong architecture-first mindset.

## Learning Journey

1. Level 1: Enterprise Knowledge Assistant
2. Level 2: Multimodal Support Triage Copilot
3. Level 3: Agentic Incident Resolution Orchestrator

## Principles

- Local-first and zero-cost by default
- Enterprise-style architecture and documentation
- Multimodal-ready design from the beginning
- Code written manually as part of the learning journey
- Production thinking introduced gradually

## Important Note

The project structure and sample data are pre-created to support learning.
Implementation code inside the application modules is intentionally left for guided manual writing.
