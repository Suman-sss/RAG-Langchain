# Level 2: Multimodal Support Triage Copilot

This level will extend the platform into multimodal ticket understanding, semantic retrieval, metadata-aware ranking, and observability.

## Data Assets Prepared

- `data/images/` contains raw screenshot-style BMP files for OCR and image-text extraction experiments.
- `data/tickets/` is ready for ticket text files.
- `data/support_docs/` is ready for runbooks and SOPs.
- `data/expected_outputs/` is ready for evaluation fixtures.
